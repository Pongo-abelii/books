本文说明本站的抄录与转载方式。

## 三种抄录方式

每篇正文上方有一条抄录工具条：

| 按钮 | 取到什么 |
|---|---|
| 纯文本 | 去掉所有排版标记的正文，粘贴到任何编辑器都不会带格式 |
| Markdown | 保留 Markdown 标记的原文，适合再加工 |
| 带出处 | 正文 + 标题 + 作者 + 链接 + 访问日期，直接可用 |
| 复制链接 | 仅本文地址 |
| 分享 | 调系统分享面板（手机端） |
| 打印 | 浏览器打印，可选存为 PDF |

## 引用格式

每篇页脚给出四种格式，点击标签切换，一键复制：

- **GB/T 7714-2015**——中文论文常用
- **MLA 9**——文学、人文学科
- **APA 7**——社科、教育
- **Chicago 17**——历史、部分人文

## 纯文本端点

每篇都有一个稳定的纯文本地址：

```
https://books.ailmel.top/raw/<路径>.txt
```

用 `curl` 直接取，返回 `text/plain; charset=utf-8`，文件头部带标题、作者、出处、授权与引用格式。不需要解析 HTML，不需要写爬虫。
